# Julia Grace Muddada — Portfolio

A simple one-page portfolio built with HTML, CSS and JavaScript.

## Preview
Open `index.html` in a browser. Internet is needed for the Google Fonts; the fallback fonts work offline.

## Before publishing
1. To add a photo: place a photo named `profile.jpg` beside `index.html`, then replace `<div class="portrait" aria-label="Photo placeholder">JG</div>` with `<div class="portrait"><img src="profile.jpg" alt="Portrait of Julia Grace Muddada"></div>` in `index.html`.
2. Add your resume as `resume.pdf` in this folder. Then change `<body>` to `<body data-resume-ready="true">` in `index.html` to enable the Resume links.
3. Check the technical content, dates, coursework and project status for accuracy.
4. Replace the general GitHub profile link with specific repository links as you finalize each project.

## GitHub Pages
Create a repository named `juliagrace07.github.io`, upload the site files to the root of the default branch, and enable Pages under Settings → Pages → Deploy from a branch. The published address should be `https://juliagrace07.github.io/` once GitHub Pages deploys it.
